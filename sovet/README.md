# Совещание Claude и ChatGPT

Две версии одной программы: консольная (`meeting.py`) и Telegram-бот (`bot.py`).
Общая логика в `core.py`.

Вы задаёте вопрос, две модели совещаются и выдают общий итог на русском.

## Как проходит совещание

1. **Claude** предлагает решение.
2. **ChatGPT** критикует: ищет риски, ошибки, пропуски.
3. **Claude** дорабатывает решение с учётом критики.
4. Пункты 2 и 3 повторяются. Всего три круга.
5. **Claude** пишет общий итог: лучший вариант с шагами, а если явного победителя нет, два или три варианта с плюсами и минусами.
6. **ChatGPT** даёт короткий вердикт: согласен или остались возражения.

## Telegram-бот

Инструкция по запуску на облачном сервере: [DEPLOY.md](DEPLOY.md).

Бот присылает отметки о ходе кругов, общий итог, вердикт ChatGPT и файл с полным протоколом.
Помнит до пяти прошлых итогов в каждом чате. Доступ ограничивается списком Telegram ID.

Запуск на своём компьютере для проверки:

```bash
pip install -r requirements.txt
cp .env.example .env     # впишите ключи и токен бота
python bot.py
```

## Консольная версия

```bash
pip install -r requirements.txt
python meeting.py
```

При первом запуске программа спросит ключи Anthropic и OpenAI и сохранит их в `.env`.
Протоколы сохраняются в папку `logs/`.

| Ключ | Что делает |
|---|---|
| `-q`, `--quiet` | не показывать ход спора, вывести только общий итог и вердикт |
| `-r 2`, `--rounds 2` | другое число кругов |
| `--once` | один вопрос и выход |

## Настройки в `.env`

| Переменная | Назначение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ Anthropic, https://console.anthropic.com/settings/keys |
| `OPENAI_API_KEY` | ключ OpenAI, https://platform.openai.com/api-keys |
| `TELEGRAM_BOT_TOKEN` | токен бота от `@BotFather` (только для бота) |
| `ALLOWED_USERS` | Telegram ID через запятую, кому разрешён бот |
| `CLAUDE_MODEL` | по умолчанию `claude-sonnet-5-5` |
| `GPT_MODEL` | по умолчанию `gpt-5` |
| `ROUNDS` | по умолчанию `3` |

Файл `.env` закрыт от git через `.gitignore`.

## Стоимость

Один вопрос при трёх кругах даёт четыре запроса к Claude и четыре к ChatGPT.
Каждый следующий запрос несёт весь ход обсуждения, поэтому длинные вопросы стоят дороже.
