# Совещание Claude и ChatGPT

Консольная программа. Вы задаёте вопрос, две модели совещаются и выдают общий итог на русском.

## Как проходит совещание

1. **Claude** предлагает решение.
2. **ChatGPT** критикует: ищет риски, ошибки, пропуски.
3. **Claude** дорабатывает решение с учётом критики.
4. Пункты 2 и 3 повторяются. Всего три круга.
5. **Claude** пишет общий итог: лучший вариант с шагами, а если явного победителя нет, два или три варианта с плюсами и минусами.
6. **ChatGPT** даёт короткий вердикт: согласен или остались возражения.

Каждое совещание сохраняется в папку `logs/` как файл Markdown.
В одном запуске можно задавать несколько вопросов подряд: модели помнят предыдущие итоги.

## Установка

Нужен Python 3.10 или новее.

```bash
cd sovet
pip install -r requirements.txt
```

## Ключи

При первом запуске программа спросит два ключа и сохранит их в файл `sovet/.env`:

- `ANTHROPIC_API_KEY`, взять на https://console.anthropic.com/settings/keys
- `OPENAI_API_KEY`, взять на https://platform.openai.com/api-keys

Файл `.env` закрыт от git через `.gitignore`, в репозиторий он не попадёт.
Чтобы сменить ключ, удалите его строку из `.env` и запустите программу снова.

Необязательные настройки в том же `.env`:

```
CLAUDE_MODEL=claude-opus-5-5
GPT_MODEL=gpt-5
ROUNDS=3
```

## Запуск

```bash
python meeting.py
```

Программа спросит вопрос. Можно передать его сразу:

```bash
python meeting.py "Как лучше продвигать сервис грузовиков в Ростове?"
```

Ключи:

| Ключ | Что делает |
|---|---|
| `-q`, `--quiet` | не показывать ход спора, вывести только общий итог и вердикт |
| `-r 2`, `--rounds 2` | другое число кругов |
| `--once` | один вопрос и выход |

Пустая строка или слово «выход» завершает программу.

## Стоимость

Один вопрос при трёх кругах даёт четыре запроса к Claude и четыре к ChatGPT.
Каждый следующий запрос несёт весь ход обсуждения, поэтому длинные вопросы стоят дороже.
