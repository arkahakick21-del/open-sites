# Как развернуть Telegram-бота на облачном сервере

Пошагово, для человека без опыта с серверами. Всё делается за 20–30 минут.

## Что понадобится

- Ключ Anthropic: https://console.anthropic.com/settings/keys
- Ключ OpenAI: https://platform.openai.com/api-keys
- Аккаунт Telegram
- Банковская карта для аренды сервера

## Важно про страну сервера

API OpenAI и Anthropic не обслуживают запросы с российских IP-адресов. Поэтому сервер
должен стоять за границей: Нидерланды, Германия, Польша, Казахстан и так далее.
Сам Telegram с сервера за границей тоже работает без ограничений.

## Шаг 1. Создать бота в Telegram

1. Откройте в Telegram бота `@BotFather`.
2. Отправьте команду `/newbot`.
3. Введите название, например `Совещание`.
4. Введите имя пользователя бота. Оно должно заканчиваться на `bot`, например `arkadiy_sovet_bot`.
5. BotFather пришлёт токен вида `1234567890:AAH...`. Сохраните его, он понадобится на шаге 5.
   Никому не показывайте токен: кто его знает, тот управляет ботом.

## Шаг 2. Арендовать сервер

Боту хватит самого дешёвого тарифа: 1 процессор, 1 ГБ памяти, 10 ГБ диска.
Операционная система: **Ubuntu 24.04**.

Примеры провайдеров на момент написания:

| Провайдер | Локация | Оплата | Примерная цена |
|---|---|---|---|
| Timeweb Cloud | Нидерланды, Польша, Казахстан | рубли, российские карты | от 250–400 ₽/мес |
| Aeza, VDSina | Нидерланды | рубли | от 200–400 ₽/мес |
| Hetzner | Германия, Финляндия | евро, нужна зарубежная карта | около 4 €/мес |

При создании сервера:

- выберите локацию **не в России**;
- выберите образ **Ubuntu 24.04**;
- если предлагают добавить SSH-ключ, можно пропустить и пользоваться паролем;
- после создания провайдер покажет **IP-адрес** и **пароль root**. Сохраните их.

## Шаг 3. Подключиться к серверу

На Windows откройте PowerShell, на Mac откройте Терминал. Введите, подставив свой IP:

```bash
ssh root@123.45.67.89
```

На вопрос `Are you sure you want to continue connecting?` ответьте `yes`.
Введите пароль root. При вводе пароль не отображается, это нормально.

Если видите приглашение вида `root@server:~#`, вы на сервере.

## Шаг 4. Установить бота

Скопируйте и выполните три команды по очереди:

```bash
apt-get update && apt-get install -y git
```

```bash
git clone --depth 1 https://github.com/arkahakick21-del/open-sites.git /opt/open-sites
```

```bash
bash /opt/open-sites/sovet/deploy/install.sh
```

Скрипт поставит Python, создаст отдельного пользователя для бота, установит зависимости
и службу автозапуска. В конце он скажет, что нужно заполнить файл `.env`.

## Шаг 5. Вписать ключи

Откройте файл настроек:

```bash
nano /opt/open-sites/sovet/.env
```

Заполните строки:

```
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...
TELEGRAM_BOT_TOKEN=1234567890:AAH...
ALLOWED_USERS=
```

Строку `ALLOWED_USERS` пока оставьте пустой, заполним на шаге 7.

Сохранение в nano: нажмите `Ctrl+O`, затем `Enter`, затем `Ctrl+X` для выхода.

## Шаг 6. Запустить

```bash
bash /opt/open-sites/sovet/deploy/install.sh
```

Теперь скрипт запустит службу и напишет «Готово. Бот работает».

Если написал, что служба не поднялась, посмотрите причину:

```bash
journalctl -u sovet-bot -n 50 --no-pager
```

Чаще всего это опечатка в ключе или токене. Исправьте `.env` и повторите шаг 6.

## Шаг 7. Закрыть бота от посторонних

Пока `ALLOWED_USERS` пуст, ботом может пользоваться любой, кто его найдёт, за ваши деньги.

1. Напишите своему боту в Telegram `/id`. Он ответит числом, это ваш Telegram ID.
2. Впишите его в `.env`:

```bash
nano /opt/open-sites/sovet/.env
```

```
ALLOWED_USERS=123456789
```

Несколько человек перечисляются через запятую: `ALLOWED_USERS=123456789,987654321`.

3. Перезапустите бота:

```bash
systemctl restart sovet-bot
```

## Шаг 8. Проверить

Напишите боту любой вопрос, например «Как привлечь клиентов в сервис грузовиков в Ростове?».
Бот ответит «Начинаю совещание», будет присылать отметки о ходе кругов, а через
несколько минут пришлёт общий итог, вердикт ChatGPT и файл с протоколом.

Команды бота:

| Команда | Что делает |
|---|---|
| `/full` | включить или выключить показ полного хода спора |
| `/rounds 2` | изменить число кругов (от 1 до 5) |
| `/reset` | забыть прошлые итоги в этом чате |
| `/status` | показать настройки |
| `/id` | показать ваш Telegram ID |

## Обслуживание

Все команды выполняются на сервере после `ssh root@IP`.

| Задача | Команда |
|---|---|
| Смотреть логи вживую | `journalctl -u sovet-bot -f` (выход: `Ctrl+C`) |
| Перезапустить | `systemctl restart sovet-bot` |
| Остановить | `systemctl stop sovet-bot` |
| Запустить | `systemctl start sovet-bot` |
| Обновить до новой версии из GitHub | `bash /opt/open-sites/sovet/deploy/install.sh` |
| Изменить ключи или модели | `nano /opt/open-sites/sovet/.env`, потом `systemctl restart sovet-bot` |

Бот сам запускается после перезагрузки сервера и сам поднимается после сбоя.

## Если что-то не так

**Бот молчит.** Проверьте, что служба работает: `systemctl status sovet-bot`.
Посмотрите логи: `journalctl -u sovet-bot -n 50 --no-pager`.

**«Conflict: terminated by other getUpdates request».** Запущены две копии бота с одним токеном.
Остановите вторую, например на своём компьютере.

**«доступ запрещён» или ошибка 403 от OpenAI или Anthropic.** Сервер стоит в стране, откуда
API не обслуживается, или на аккаунте нет средств. Проверьте локацию сервера и баланс.

**«модель не найдена».** На вашем аккаунте нет такой модели. Поменяйте `GPT_MODEL` или
`CLAUDE_MODEL` в `.env` на доступную и перезапустите.

**Бот отвечает «Этот бот частный».** Ваш ID не вписан в `ALLOWED_USERS`. См. шаг 7.

## Безопасность и деньги

- Закройте лишние порты: `ufw allow OpenSSH && ufw enable`. На вопрос ответьте `y`.
- Файл `.env` доступен только пользователю бота. Не выкладывайте его и не присылайте в чаты.
- Одно совещание при трёх кругах делает восемь запросов к моделям. Ориентировочно это
  от 0,3 до 1 доллара, в зависимости от длины вопроса и ответов. Следите за балансом
  в кабинетах OpenAI и Anthropic и поставьте там лимиты расходов.
