# Ассистент по Instagram в Telegram

Личный Telegram-бот для специалиста по Instagram. Она пишет задачу текстом или голосом
и присылает видео. Бот передаёт задачу Claude Code на сервере. Claude Code монтирует,
пишет тексты, смотрит статистику и присылает результат обратно в Telegram.

## Что умеет

- **Монтаж Reels.** Обрезка, склейка, кадрирование в 9:16, вырезание пауз, ускорение, музыка, обложки, текст на экране.
- **Субтитры.** Речь распознаётся с точностью до слова. Субтитры в стиле Reels с подсветкой произносимого слова, цвет, размер и шрифт настраиваются.
- **Тексты.** Подписи, хештеги, сценарии, контент-план, ответы на комментарии.
- **Аналитика.** Статистика публикаций и советы, если Instagram подключён.
- **Публикация Reels.** Бот присылает подпись и кнопку «Опубликовать». Без нажатия ничего не публикуется.
- **Голосовые сообщения.** Задачу можно надиктовать.
- **Память.** Бот помнит разговор, поэтому можно уточнять: «субтитры крупнее», «обрежь начало». Стиль роликов и сведения об аккаунте он записывает в заметки и помнит всегда.

## Как это устроено

```
Telegram  ->  bot.py  ->  agent.py (Claude Code через Claude Agent SDK)  ->  ffmpeg, распознавание речи, Instagram API
   ^                                                                                  |
   +----------------------- ответ и готовые файлы из папки out/ ---------------------+
```

| Файл | Что делает |
|---|---|
| `bot.py` | Telegram: принимает задачи и файлы, показывает ход работы, отправляет результат, кнопки публикации |
| `agent.py` | запускает Claude Code в рабочей папке, в нём же инструкция ассистенту |
| `tools/transcribe.py` | распознавание речи и субтитры для Reels |
| `tools/ig.py` | статистика Instagram и заявка на публикацию |
| `instagram_api.py` | работа с официальным Instagram API |

Рабочая папка `data/workspace`:

- `inbox/` для присланных файлов;
- `out/` для готовых результатов, бот отправляет их автоматически;
- `work/` для черновиков;
- `NOTES.md` для долгих заметок об аккаунте.

## Команды бота

| Команда | Что делает |
|---|---|
| `/new` | начать новую тему; заметки об аккаунте сохраняются |
| `/cancel` | остановить текущую задачу |
| `/files` | что лежит в папках и сколько места на диске |
| `/clean` | удалить старые файлы |
| `/status` | состояние бота, расход, подключение Instagram |
| `/id` | показать свой Telegram ID |

## Установка

Пошагово для облачного сервера: [DEPLOY.md](DEPLOY.md).

Проверка на своём компьютере, нужны Python 3.10+ и ffmpeg:

```bash
pip install -r requirements.txt
cp .env.example .env     # впишите токен бота, ключи и свой Telegram ID
python bot.py
```

## Подключение Instagram

Монтаж, субтитры и тексты работают без этого. Подключение нужно для статистики и публикации.
Используется официальный «Instagram API with Instagram Login». Страница Facebook для него не нужна.

1. В Instagram переключите аккаунт на профессиональный: Настройки, Тип аккаунта и инструменты, Переключиться на профессиональный аккаунт. Подходит «Автор» или «Бизнес».
2. На https://developers.facebook.com создайте приложение. Тип использования выберите про Instagram: управление сообщениями и контентом.
3. В приложении откройте Роли приложения и добавьте её аккаунт Instagram как тестировщика. Она принимает приглашение в Instagram: Настройки, Приложения и сайты, Приглашения тестировщиков.
4. В разделе Instagram, настройка API с входом через Instagram, добавьте аккаунт и сгенерируйте токен. Нужны разрешения `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_insights`.
5. Впишите токен в `.env` в строку `IG_ACCESS_TOKEN` и перезапустите бота. Команда `/status` должна показать имя аккаунта.

Приложение может оставаться в режиме разработки, если им пользуется только её аккаунт с ролью в приложении.
Проверка Meta нужна, только если подключать чужие аккаунты.
Токен живёт 60 дней, бот продлевает его сам раз в сутки.

Публикация Reels написана по документации Meta и проверена на заглушках. На настоящем аккаунте её нужно проверить при первом подключении.

## Безопасность

- Бот отвечает только Telegram ID из `ALLOWED_USERS`. Если список пуст, бот никого не пускает.
- Ассистент выполняет команды на сервере. Служба systemd разрешает ему писать только в папку бота и свою домашнюю папку.
- Публикация идёт только по кнопке в Telegram. Удалять посты, писать комментарии и сообщения в директ ассистент не может.

Сложный монтаж из нескольких роликов стоит дороже. Предел расходов на одну задачу задаётся в `MAX_TASK_USD`, по умолчанию $5.
Общий расход показывает `/status`.
