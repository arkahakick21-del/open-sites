# БДДС ООО «ММА23» на 2027 год

Бюджет движения денежных средств для транспортной компании: план на 12 месяцев,
журнал фактических платежей, автоматический факт и сводка план/факт с графиками.

Файл: `MMA23_BDDS_2027.xlsx` (открывается в Excel и Google Таблицах).
Рабочая копия ведётся в Google Таблицах на Google Диске.

Листы:
- **Сводка** — выбор месяца, ключевые показатели, план/факт/отклонение по статьям, графики.
- **План** — план по статьям на 12 месяцев (синие ячейки вводятся вручную).
- **Факт** — считается сам из журнала «Платежи».
- **Платежи** — журнал операций: дата, статья из списка, сумма, контрагент.
- **Настройки** — первый месяц бюджета, остаток на начало, неснижаемый остаток, справочник статей, инструкция.

Генератор: `build_bdds.py` (Python, openpyxl).
